# VXKey 1.0.1

Hiển thị đúng icon VXKey nền xanh trong bộ cài và Dock.

[Tải cho Mac Apple Silicon](https://github.com/linhbv94/VXKey/releases/download/v1.0.1/vxkey_1.0.1_macos_silicon.dmg). Nếu đang dùng1.0.0, mở Cài đặt → Cập nhật để tải và cài phiên bản mới.

Các lỗi gõ còn được theo dõi ở1.0.0 tiếp tục được sửa trong các bản sau.
